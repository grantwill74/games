Some of my games

GitHub repository

  • Magispells, (alpha 2) a word-matching puzzle game, inspired by Bookworm. Play the best word you can. After each word, the game will pick a random tile and play the best word it can. If it beats your word, the better word's tiles will freeze, making them nearly worthless. Achieve a certain number of points in a limited number of turns to level up and keep play.
  • Truffle Shuffle A minesweeper-inspired game. You're a pig looking for truffles, but the field is full of gopher holes! Press A (z on the keyboard) to dig, and press B (x on the keyboard) to plant a flag. You have 3 flags but you don't lose one if you're right. There are 10 randomly- generated levels. See how fast you can win!
  • JumpSolitaire A simple peg-jumping solitaire game for the TIC-80. It has a DP solver that works for all the boards, and a forward solver that is only used in the English Cross board. The solvers depths' aren't great (6 moves in either direction), so the "unwinnable" message may be late for the last board. Good way to learn the simpler kinds of peg solitaire though. Programmed in Fennel.
  • BrightOn: a simple puzzle game inspired by LightsOut. My first game for the TIC-80. Programmed in Fennel.
